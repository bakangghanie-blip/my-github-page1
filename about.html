About Cybertec

Who we are and what we do

Our Story

Cybertec was created as a university project to demonstrate a fully functional cybersecurity company website. The goal was to apply web development skills including HTML5, CSS3, JavaScript, and responsive design.

What This Site Shows

This website includes five pages: Home, About, Services, Solutions, and Contact. It features a dark theme, responsive layout, working navigation, and a contact form with validation.

Technologies Used

  • HTML5 for structure
  • CSS3 for styling (dark theme, grid layout, responsive)
  • JavaScript for mobile menu and form validation
  • GitHub Pages for hosting

Assignment Context

This website is part of the Web & Multimedia Development module, Year 1 Semester 2. It meets the requirements of at least five interlinked pages, a feedback form, and cross-browser compatibility.
